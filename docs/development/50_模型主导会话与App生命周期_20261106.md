# 模型主导会话与 App 生命周期改造（2026-11-06）

## 范围与状态

本记录描述本次候选版本及发布前验证。改造目标是让 DeepSeek 在每轮读取当前会话原文和可核对的交互、任务状态后，决定任务关系与工具调用；服务端继续负责版本、权限、地点身份、路线结果和时限校验。本轮不运行论文实验，也不删除既有服务器诊断历史。

记录编写时，生产运行提交仍为 `222ed9ff8fe863c1ce5aad7ea32ee1e72652b301`。实际部署、备份和上线后的检查应另行记录，不能将本文件中的候选版本验证当作生产验收。

## 实现

- 先保存消息并创建与会话关联的待理解运行；任务及版本在模型决定新建、继续或恢复后事务性绑定。会话内运行按消息顺序领取；提交和最终交付均核对消息、租约与任务版本，较旧结果不能覆盖新输入。请求 ID 保持去重。
- 模型输入包含完整用户和助手原文、历史消息的交互元数据、可用任务状态、已展示地点和结果引用；大体积路线几何按引用分页读取。网页显示的模型回复和服务器保存的助手文本使用同一份内容。取消操作和超时反馈也进入会话记录。
- 地点候选、已选地点、实际起点、搜索中心及半径分别保存。默认半径 1000 米；用户仅要求扩大且未指定增幅时翻倍，上限 5000 米。候选浏览返回具体 ID、位置和耗尽状态；已展示 ID 不再按固定条数截断。地点 ID、坐标及路线仍需经过服务器和工具核验。
- 模型决定调用地点、路线、天气、道路事件和网页工具；生产模型路径不再按固定换批短语或预判任务类型绕过模型。服务错误以可重试失败反馈，而不是转换成意图追问。任务期限从提交时起算 75 秒；模型与主要网络工具读取剩余时间，结果提交时拒绝过期运行。
- 数据库迁移 `016_model_conversation_runs.sql` 为旧运行回填会话归属，并通过兼容触发器支持旧式已绑定运行写入。旧提交 `222ed9f` 的任务状态校验和部分 SQL 无法直接适配扩展后的数据；应急回退使用兼容提交 `d0241b662286533160b229b75c46abd25f9d2c35`，先停止入口并结束所有未绑定运行，不删除扩展字段或诊断记录。
- App `1.4.2`、`versionCode 7` 在原生启动时生成会话标识，系统重建时从保存的实例状态恢复；WebView 刷新和普通后台返回沿用当前标识。前端不再从旧的长期共享键自动恢复历史对话；浏览器使用标签页会话。此生命周期行为仍需真机验证。
