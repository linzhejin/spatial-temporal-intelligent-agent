# 珞珈智行：本轮收尾与部署验收（2026-10-26）

## 发布范围

产品代码、隔离路况开发回放工具及对应文档已提交为 `37ae8a2d3e5e96afca6a82edadea0ff9e1046ed3`，快进同步到 GitHub、Gitee 的 `main`。腾讯云项目目录也更新至同一提交；桌面主工作区的未提交文件未参与发布。

本轮产品修复是：算路器确认图中无可行路时，Agent 返回带起终点和方式的明确答复，不再把旧路线留在地图上；原任务条件留作再次规划。多工具批次里已有成功路线、澄清或路线对比时，不让同批的无路结果覆盖它们。前端脚本与 Service Worker 版本分别更新为 `20261026-no-route2`、`whu-walker-v95`，使浏览器获取本轮代码。

研究工具提供逐题独立的本地 PostgreSQL、模拟路况文件、冻结时间、Agent 进程及经验和溯源记录；脚本禁止将默认业务存储当作实验环境。它没有把模拟路况写入生产库。

## 论文实验状态与下一步

隔离模拟事件的两次开发运行分别得到 2/2 和 1/2 的**投影规则**通过。第二次的绕行题在查路况、解析地点后超时，未调用算路；这是待解决的 Agent 时延或编排问题。结果未经独立来源核验，也不是盲测或现场通行证据，不能写作正式成功率。

下一步依次处理该超时链路，冻结来源和独立判分器，准备与开发题不重叠的盲测，再进行同底模对照、消融与少量代表性路线核查。视觉影像继续用公开样本验证“候选事件→人工复核→路况生效→路线重算”，模型效果和模拟位置分别报告。当前无需用户逐条采集校园道路；遇到真正歧义样本、道路对应或正式付费预算时再集中提交人工判断。
