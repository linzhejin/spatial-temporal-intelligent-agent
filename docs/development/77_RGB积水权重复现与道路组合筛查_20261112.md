# RGB 积水权重复现与道路组合筛查

日期：2026-11-12。续 66 至 76 号记录，保留此前失败证据。

## 结论

在隔离环境运行了一份公开 RGB 航拍积水分割权重，并与先前道路分割结果组合。当前复现对差异很大的输入产生近似固定的掩膜；道路组合在 8 张没有淹水道路标注的图片上均产生候选。**结果不支持开放免圈选积水候选。**

本次只能说明所下载权重与当前复现方式的表现，不能断定作者原环境的模型性能。没有修改生产、训练模型、使用付费计算或启用事故模型。图片、权重、隔离环境及逐图证据保存在 Git 以外。

## 模型和复现

- [flood-seg-net 作者仓库](https://github.com/1ens0r/flood-seg-net/tree/5f580fed8a4d6fb9f63eba6ccf07db540e49c171) 修订 `5f580fed8a4d6fb9f63eba6ccf07db540e49c171`；下载的 `best_model_colab.keras` SHA-256 为 `a12e75a7a8a06a48c47522f223233fd29d799cbaedd79445bae489fe1200c903`。作者未提供可对照的哈希；该哈希只标识本次取得的文件，不构成作者侧完整性证明。作者仓库未见明确的代码和权重许可，不能直接用于产品。
- 参考作者 `inference.py`：RGB、缩放到 256×256、除以 255、以 0.5 阈值二值化，再用最近邻插值恢复尺寸。模型仅处理单张 RGB 图；不同于直接输出“淹水道路”，其目标为二值水域。训练说明引用 290 张洪水场景影像，不能据此认定其已可靠区分积水与常年水体。
- 使用 Python 3.12、TensorFlow 2.20.0、Keras 3.13.2、CPU 和 `compile=False` 直接加载，模型具有动态图像尺寸；实际输入及输出均校验为 256×256。关闭 oneDNN，尚未和作者完整环境逐图数值对齐。同一张输入下 `model.predict()` 与直接推理的最大差为 0，只验证这两种本地调用一致。
- 首次在 Python 3.10 隔离环境安装 Keras 3.13.2 失败，因其要求较新 Python；随后改用本机既有 Python 3.12 新建隔离环境。首次推理时误以为模型要求固定尺寸，形状断言失败；检查到模型的高宽为动态尺寸后，改为校验通道、允许的动态尺寸以及实际输入输出形状，再执行推理。两次失败没有作为模型结果。

## 管线诊断

对全黑和全白合成输入，输出二值掩膜约有 **99.72%** 的像素相同，分别约有 90.56%、90.73% 被判为水域；两者概率图平均绝对差约 0.0056。不同公开图片的输出也呈现相似现象。这是异常信号，不是精度指标；目前不能排除权重版本、保存过程或运行环境因素。

作者训练笔记显示 NumPy 2.0.2；主筛查使用 1.26.4。另在不修改原环境的隔离目录中切换到 2.0.2，展示图输出与原结果最大差为 0，黑图与白图的二值掩膜仍约 99.72% 相同。该检查排除了这一项版本差异造成的本地结果变化，不能替代完整环境对齐。

另从作者已发布的两张可视化图中截取输入面板，按上述流程推理并与作者发布的预测掩膜比较：两个样例的非水域交并比均为 0。面板来自缩放后的截图，而非作者原始图片，此检查**不能作为严格的作者环境对齐**，只能说明当前复现结果与发布示例存在值得注意的差异。

## 道路组合筛查

复用此前已参与筛查的 4 张 Hurricane Ian 图片及 16 张 Hurricane Delta 图片；标签只用于筛选和事后计分，不输入模型。16 张中 8 张有淹水道路标注、8 张没有；后者不等于整张图一定不存在洪水。候选由本地原型的轮廓生成逻辑产生并近似栅格化。各模型的原环境对齐和独立测试均未完成。

| 16 张 Delta 图的组合 | 8 张正例有候选与标注相交 | 8 张无淹水道路标注图有候选 | 已标注淹水道路覆盖率 | 候选轮廓位于道路标注外 |
| --- | ---: | ---: | ---: | ---: |
| 仅水域掩膜 | 8 | 8 | 约 96.36% | 约 96.76% |
| SatLens 道路与水域直接相交 | 6 | 8 | 约 13.46% | 约 26.41% |
| UPerNet / Swin 道路与水域直接相交 | 7 | 8 | 约 24.23% | 约 33.64% |

“有相交”只表示至少一个像素重合。水域掩膜大面积覆盖画面，因此它的道路覆盖率不能解释为成功识别了积水道路。道路标注外也不必然是现实中没有道路。SatLens 及 UPerNet 的版本和限制见 76 号记录；其中 UPerNet 的许可和预处理未经确认。没有用上述组合选择正式阈值。

用户展示图有 16,879 个标注淹水道路像素：SatLens 直接相交后产生 22 个候选，覆盖约 21.58%，约 26.24% 的候选像素位于道路标注外。UPerNet 直接相交覆盖约 38.61%，约 19.30% 位于标注外，但其许可及预处理仍不明。一张没有淹水道路标注的 Ian 对照图在两种组合下分别产生 6 个候选。
