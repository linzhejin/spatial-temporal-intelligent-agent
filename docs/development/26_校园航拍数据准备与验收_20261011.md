# 校园航拍数据准备与验收（2026-10-11）

## 本轮完成内容

- 新增 `vision/campus_water_data.py`，校验校园航拍清单并按完整视频时间范围抽帧。
- 新增 `scripts/vision/prepare_campus_water_data.py`，支持只读预检和正式生成标注包。
- 强制训练、验证、测试航次互斥；同一 `site_id` 也不得跨集合，避免同地点画面泄漏。
- 每个航次必须记录地点和带时区的拍摄时间；原视频及可选字幕、飞行日志均记录字节数与 SHA-256。不同文件名但内容完全相同的原视频也会被拒绝。
- 输出训练与测试独立模板。测试航次不会进入训练模板，人工标注前模板保持 `annotation_pending: true`。
- 默认按 1 fps 抽帧，但仍完整解码视频，不以固定帧数截断长视频。每张图记录源帧号和时间戳。
- 已存在的输出目录不会被覆盖；中途失败保留 `.partial` 目录，避免误删原始工作。

## 输出目录

```text
campus-water/
├── ANNOTATION.md
├── annotation-worklist.json
├── training-template.json
├── test-template.json
├── detection-test-template.json
├── event-test-template.json
├── frames/
│   ├── train/<flight_id>/*.jpg
│   ├── validation/<flight_id>/*.jpg
│   └── test/<flight_id>/*.jpg
└── masks/
    ├── train/<flight_id>/*.png
    ├── validation/<flight_id>/*.png
    └── test/<flight_id>/*.png
```

`masks/` 初始为空。标注人员必须保存与原图同尺寸的灰度 PNG，0 表示非水体、255 表示确认的可见水体；同时填写归一化道路多边形。阴影、湿路反光、湖面和不确定区域不能猜成道路积水。

`detection-test-template.json` 只包含测试航次的抽帧，用于人车框标注。先删去不准备标注的冗余相邻帧，再在保留帧的 `objects` 中填写 `pedestrian`、`vehicle` 或 `ignore` 和像素框 `[x1,y1,x2,y2]`。真正没有目标的人工确认帧可以保留空数组；尚未检查的空数组不能当作负样本。车辆统一按路线感知所需的 vehicle 组评测，不把车型细分准确率混入本阶段结论。

`event-test-template.json` 为每个测试航次保留原视频路径、来源哈希、地点和拍摄时间，并把镜头稳定性、已检查事件类型、观察区域和事件时间段留作待填字段。完成逐段人工检查后删除 `annotation_pending`；运行统一事件评测时，`--manifest` 指向该模板的已标注副本，`--dataset-root` 指向原始航拍数据目录。

## 验收边界

这套工具证明的是数据来源可追溯、视频覆盖完整以及训练/测试隔离。它不证明模型已经识别武大积水或准确检出校园人车，更不能直接发布路况。只有独立测试航次完成人车框、道路 ROI 和事件标注并达到相应指标后，才讨论启用可选模型；所有候选仍须管理员复核。

当前专项测试覆盖清单分组、路径越界、路径重复、内容哈希重复、时间地点元数据、地点跨集合泄漏、原片哈希、视频提前截断、抽帧时间戳、模板隔离、拒绝覆盖和命令行只读预检。

同一批完整原片还会生成待标注的 `campus_event_detection` 清单，用于车辆拥堵、人流拥挤、事故和积水的事件级评测。事件清单保留完整视频，不拿相邻帧充当独立样本；每段测试视频明确声明已人工检查的事件类型、观察区域和起止时间。执行入口、区域类型约束和示例见 [`22_无人机专用模型接入与评测.md`](22_无人机专用模型接入与评测.md#校园多事件统一评测)。

人车框标注完成后，用在验证航次冻结的置信度运行：

```powershell
python scripts/vision/evaluate_campus_detection.py `
  --manifest D:\LuoJiaExperimentData\WHUWalker_vision_research\campus-water\detection-test.json `
  --dataset-root D:\LuoJiaExperimentData\WHUWalker_vision_research\campus-water `
  --model D:\LuoJiaModels\visdrone-rtdetrv4-s.onnx `
  --confidence 0.369 --iou 0.5 `
  --output D:\LuoJiaExperimentData\WHUWalker_vision_research\campus-detection-report.json
```

报告分别给出 pedestrian、vehicle 的框级 TP/FP/FN、precision、recall、F1 和按测试航次重采样的区间。框级结果与拥堵、人流、事故、积水的事件级结果分开报告。
