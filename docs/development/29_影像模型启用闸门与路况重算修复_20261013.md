# 影像模型启用闸门与路况重算修复（2026-10-13）

## 本次处理

本地审查发现两个影响“识别结果能否可靠进入路线”的问题：

1. 事故和积水模型只要环境变量打开且权重路径存在，就会尝试加载；它们没有被强制绑定到授权记录、精确模型哈希和校园现场验收报告。
2. 用户端检测到路况版本更新后，按钮向 `/api/route/replan` 发送空变更；后端只接受策略或出行方式修改，因此这个重算请求会返回 `400 invalid_route_state`。

已增加默认拒绝的可选模型启用检查。最初事故门槛曾要求校园事故正例；该历史规则已在下方按“公开视频正例＋校园正常航次误报检查”修正。积水模型仍须匹配严格校园报告，并达到道路可见水 IoU ≥ 0.60、至少 3 个独立测试航次。可选模型均校验实际权重 SHA-256、版本、报告 SHA-256 和带时区的批准时间；任一材料缺失、过期或不匹配，都不会加载可选模型。

## 事故证据口径修正（2026-10-14）

上段原门槛把“事故正例必须来自校园测试航次”写成了启用要求，与本项目采用公开事故正例的方案冲突。现将**校园效果声明**和**事故候选筛查启用**分开：

- 事故正例由独立公开视频事件基准提供，须按完整事故、航次或场景隔离训练/验证/测试组，包含真实来源 URL、许可标识和许可依据；测试至少 3 个独立组且至少一个正例组，事件级 precision ≥ 0.90、recall ≥ 0.80。按事件窗口评测的公开视频证据不等于 AIDER 静态图片分类分数。
- 校园数据单独提供至少 3 个经人工检查的事故观察航次；这些航次可以都是正常交通画面，不要求在学校拍到事故。每段校园事件测试视频须与已校验的校园飞行清单逐条对应：测试航次 ID、原片相对路径和原片 SHA-256 必须一致；事故候选的校园评测必须零误报，且模型、阈值和结果哈希相符。公开视频或未登记视频不能充当校园误报证据。
- 满足以上条件只允许事故模型生成**供管理员复核的候选**。这不开放“校园事故识别精度”主张，也不允许模型直接封路。要宣称校园事故识别精度，仍须有独立校园正例及完整校园事件评测。
- 事故候选仍须通过管理员逐条确认、选择道路和有效期后才影响路线。权重哈希、阈值、授权记录、审批时限、就绪报告时效继续执行原检查。积水模型的校园道路分割门槛不变。

就绪审计新增 `external_accident_evaluation`，并核对外部清单、评测报告、模型哈希、阈值、逐样本计数、独立测试组、正例组和置信区间。`event_evaluation.campus_negative_safety_ready` 只有在校园航次原片三项绑定、至少 3 个事故观察航次、评测报告有效且零误报时才为 `true`。启用清单还须有独立的 `benchmark_approval`，其审批记录绑定公开基准清单 SHA-256，并包含审核人、依据和有效期；程序只核对记录与哈希，不会替审核人验证数据来源或许可证真实性。校园 `accuracy_claim_allowed` 仍按严格校园正例计算，不会被外部基准提升为 `true`。

管理员状态接口把被验收闸门拦截的模型显示为“尚未验收，暂不启用”，不会误报成权重加载故障。启用清单由部署管理员维护，`rights_evidence` 应指向实际许可证审查材料；本程序校验记录字段与报告哈希，不替代法律审查，也不验证签署人身份。批准时间不能在未来，必须设置未来的 `approval_expires_at`，且批准有效期最长为 365 天；校园就绪报告带有生成时间，最多接受 90 天内生成的报告，未来时间或过期报告一律拒绝。

路况更新按钮现在发送显式 `refresh_road_conditions: true`。服务端仅刷新路线所依据的当前路况快照，继续保留原路线起终点、途经点、出行方式、硬约束和策略；普通空变更仍然拒绝。

## 启用材料配置

新增两个不提交到版本库的部署环境变量：

```dotenv
VISION_OPTIONAL_MODELS_RELEASE_MANIFEST=/secure/path/optional-models-release.json
VISION_FIELD_READINESS_REPORT=/secure/path/campus-field-readiness.json
```

审计若要核对公开事故事件基准，再传入 `--external-accident-manifest` 和 `--external-accident-report`；报告由 `scripts/vision/evaluate_accident_events.py` 生成。外部基准清单需额外包含 `source_provenance`：`source`、`url`、`license`、`license_evidence`。这两个参数不能代替 `--event-manifest/--event-report` 的校园正常交通复核。

报告通过既有 `scripts/vision/audit_campus_field_readiness.py --strict --output ...` 生成。先人工复核授权后，管理员再维护清单。最小结构如下，所有 `<...>` 都必须替换为真实证据，不能把此示例当作通过材料：
