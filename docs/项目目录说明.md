## 源码与资料的用途

| 文件夹 | 存放内容 |
|---|---|
| `agents/` | 智能体、工具和任务状态 |
| `api/` | HTTP 接口 |
| `spatial/` | 路网计算、地点检索和道路事件 |
| `vision/` | 影像识别与证据处理 |
| `jobs/` | 后台任务 |
| `storage/` | 数据库访问与迁移 |
| `static/` | 网页和地图前端 |
| `android-app/` | Android 壳应用及构建 |
| `data/` | 产品地点、路网和基础空间数据 |
| `experiments/` | 实验运行器、协议、任务与评分器 |
| `tests/` | 自动化测试源码 |
| `scripts/` | 开发、验证和维护脚本 |
| `ops/` | 运行维护与部署辅助 |
| `docs/` | 使用文档、当前进度和历史证据 |
| `output/` | 本机运行记录、人工审查与生成文件 |
| `research/` | 论文、比赛等本机资料；本轮保留 |
| `legacy/` | 旧部署方案，当前不作为默认启动入口 |

根目录 `app.py` 是服务入口，`config.py` 为配置读取；`README.md` 介绍运行方式，`HANDOFF.md` 为当前交接入口，`requirements*.txt` 为依赖列表。

源码、Git 工作树、实验和原始证据的路径是程序引用的一部分，因此保留已有名称。中文入口负责说明用途，避免改目录后导入失败、哈希失效或抽审页面打不开。
