# 07 · 前端指南

前端是无框架的原生 JavaScript 单页应用，全部代码在 [static/](../static/)：

| 文件 | 职责 |
|---|---|
| [index.html](../static/index.html) | 唯一页面，全部 DOM 结构 |
| [js/app.js](../static/js/app.js) | 主逻辑（约 3600 行，IIFE 闭包）：地图、对话、请求、定位、路况、出行方式、快捷键，末尾另有冷启动欢迎卡与 PWA 安装横幅两个独立模块 |
| [js/route-state.js](../static/js/route-state.js) | 路线状态事务：开始、提交、回滚及并发响应防覆盖 |
| [js/navigation.js](../static/js/navigation.js) | 实时导航引擎（`window.WhuWalkerNavigation`） |
| [js/voice-input.js](../static/js/voice-input.js) | 按住说话语音输入（`window.WhuWalkerVoiceInput`） |
| [js/voice-output.js](../static/js/voice-output.js) | TTS 语音播报（`window.WhuWalkerVoiceOutput`） |
| [js/config.js](../static/js/config.js) | 磁盘上的兜底配置；线上 `/js/config.js` 实际由 Flask 动态生成，注入高德 Key 与地图中心（见 [app.py](../app.py) 的 `serve_config_js`） |
| [sw.js](../static/sw.js) | Service Worker（缓存名以文件内 `CACHE_NAME` 为准，随发版递增） |
| [manifest.json](../static/manifest.json) | PWA 清单 |
| [css/style.css](../static/css/style.css) | "珞珈秋色"设计系统与响应式布局 |
| [vendor/leaflet/](../static/vendor/leaflet/) | Leaflet 1.9.4 本地副本（CSS/JS/图片），不依赖 CDN |

## 页面结构（按真实 DOM）

桌面端是 CSS Grid 左右分栏（360px 对话面板 + 1fr 地图，≥1200px 时对话栏 380px）；≤767px 移动端变为上下两块（地图 55vh 在上、毛玻璃对话面板在下）。

- `#map-panel` 沉浸式地图面板：`#map-container` Leaflet 容器与加载占位符；`#map-legend` 图例（推荐线 / 最短路径 / 景点 / 管制封闭 / 管制缓行）；自定义的起点 / 途经 / 终点选点控件。
- `#nav-overlay` 沉浸导航浮层（默认 hidden）：顶部大指令卡 `#nav-card`（转向箭头、距离、文案）、GPS 弱网黄条、重居中按钮、轻提示 toast、到达卡 `#nav-arrive`、底部剩余距离 / 时间 / 静音 / 结束条。
- `.chat-panel` 对话面板：
  - `.floating-header` 浮动顶栏：标题、天气徽章 `#weather-badge`、🚧 路况上报、↺ 重置、? 帮助按钮；
  - `#mode-bar` 出行方式分段选择器（始终可见）及路线生成后出现的最短 / 风景 / 平坦偏好选择器；
  - `#chat-content` 对话滚动区：欢迎气泡、两张对话内迷你快捷卡、`#results-section` 结果区（推荐距离 / 预计用时 / 最短距离 / 重叠率四摘要卡、开始导航按钮、途经景点、路线说明、"你可能想问"跟进建议）；
  - `#chat-input-bar` 底部输入区：`#nl-input`（placeholder「我是你的智能助手，想去哪儿？」，200 字上限 + 字数统计）、麦克风、发送按钮；
  - `#kbd-hint-bar` 快捷键提示行（仅桌面端显示，移动端 CSS 隐藏）。
- 全局浮层：Loading 遮罩、错误弹窗、快捷键帮助弹窗、管理员登录弹窗、路况上报表单弹窗、`#welcome-overlay` 冷启动欢迎覆盖层、`#install-banner` PWA 安装引导横幅、`#loc-status` 定位状态指示器。

对话气泡由 JS 动态创建（`showUserBubble` / `showChatBubble`）。普通浏览器刷新会从 localStorage 的最近 8 轮历史恢复最近 3 轮，以延续上下文；顶栏应用内“刷新”原地清空当前路线和对话，开始新会话，不触发历史恢复。

## 地图引擎与 GCJ-02 统一约束

地图用 Leaflet 1.9.4（本地化加载），底图只有高德两套瓦片，均为 GCJ-02 坐标系、无需 Key：

- 高德矢量（默认）：`webrd0{1-4}.is.autonavi.com/appmaptile?...&style=8`，maxZoom 18；
- 高德卫星：`webst0{1-4}` 的 style=6 影像叠加 style=8 路网注记，图层控件可切换。

**全站坐标系统一 GCJ-02**：POI、路线、GPS 蓝点在入图前都转为 GCJ-02，与底图天然对齐。代码注释明确禁止接入 OSM / Esri / 天地图 vec_w 等 WGS-84/CGCS2000 底图——同一套 GCJ-02 路线叠上去会串位数百米。后端 OSM 路网计算仍在 WGS-84 进行，仅在出参时转换。高德 JS SDK 2.0 只用来取 `AMap.Geolocation` 混合定位（WiFi/基站/GPS），异步加载、`onerror` 静默降级；不承担任何底图与路线绘制。

地图默认中心 `[114.3630, 30.5365]`、缩放 16（手机端初始 14），并带图层控件、比例尺。

## 路线绘制：推荐 / 最短双线

`renderRoute(routeData)` 绘制后端返回的 GCJ-02 坐标：

- 推荐路线实线，配色随出行方式（`TRAVEL_MODES`）：步行樱花粉 `#E8929C`、骑行松绿 `#7BA37B`、驾车黛蓝 `#6A9FB5`；普通线宽 6，导航中加粗到 7。
- 最短路径灰色虚线对照：`#B5B0AB`、`dashArray: '6,8'`；导航态下隐藏，不干扰沉浸视图。
- 沿线 POI 最多标注前 8 个（古铜金小圆点），非导航态自动 fitBounds 到全部要素。

## 出行方式切换与请求序号防串扰

- 方式固定默认步行（每次刷新重置，不持久化）；点击分段按钮或按 1/2/3 切换。服务端在自然语言里识别到"骑车 / 开车"时以服务端返回的 mode 回写选择器（`syncModeFromServer`）。驾车模式下"平坦优先"无意义，会清除其高亮。
- 路线生成后，浏览器保存服务端签发的完整 `route_state`。切换方式或偏好统一请求 `/api/route/replan`，不走大模型；成功后才提交新状态，失败时保留原路线、途经点、游览点和硬约束。
- **请求序号防串扰**：所有异步链路（方式重算、地图选点自动规划、自然语言提交、偏好快捷模式）发起前 `state.requestSeq += 1`，回调里比对 `mySeq !== state.requestSeq` 即丢弃过期响应，杜绝"先发后至"的旧结果覆盖新状态。
- 无途经点的地图选点规划直连 `/api/route`，带途经点走 `/api/chat`（Agent 支持 coord_waypoints）。
- 已有路线时，页面按钮和快捷键 F / S / D 都走同一个原子重规划入口；没有路线时才按默认示例起终点发起首次规划。

## 定位体系

- App 内走原生桥 `WhuWalkerLocation`（权限授予成功后才启动，时序确定，带罗盘融合航向）；浏览器内 `navigator.geolocation.watchPosition`（高精度）失败后降级高德 WiFi 定位，两条流可并存、渲染幂等。
- 两段式先粗后精：先 `getCurrentPosition` 低精度网络定位秒出占位点（标记 provisional），GPS 精修无条件接管。
- 蓝点抖动抑制：隐含速度 >25 m/s 的异常跳变丢弃（连续 5 次则强制修复）；落在旧点精度圈噪声内的点钉住蓝点只收紧精度圈，连续 10 次强制校准。最近一次可信位置缓存 24 小时，下次打开先秒显。
- 定位更新同时分发给导航订阅者（`subscribeLocation` / `locSubscribers`），导航只消费不干预蓝点逻辑。

## 语音输入：按住说话

交互在 app.js 与 voice-input.js 两层实现：Pointer Events 统一处理鼠标 / 触摸——`pointerdown` 开始、`pointerup` 发送、上滑超过 70px（`VOICE_CANCEL_DY`）单向取消。页面上动态插入 `.voice-hold-card` 紧凑聆听胶囊：「正在聆听…」、实时 partial 转写、音量缩放动效、「松开发送 · 上滑取消」，取消态变「松开取消」。

能力探测 `capability()`：App 内存在 `WhuWalkerVoice` 桥则走原生识别；否则用 `webkitSpeechRecognition`（zh-CN、interimResults）；微信内置浏览器（MicroMessenger）和不支持环境给出"在浏览器打开 / 安装 App"的横幅引导。识别结果 final 后自动回填输入框并触发发送。Android 侧的 30 秒最长按住、松手 2.5 秒静默超时等细节见 [10_移动端与语音导航.md](10_移动端与语音导航.md)。

## 语音播报

`WhuWalkerVoiceOutput.speak(text)`：App 内优先调原生 `WhuWalkerTts.speak()`（返回 false 表示未受理，则浏览器兜底），浏览器用 `speechSynthesis` 并提前挑选 zh-CN 语音。语义是 **QUEUE_FLUSH**——新播报打断旧播报（导航指令必须及时）；静音偏好存 localStorage（`whu_walker:voice_muted`），导航底部 🔊 按钮可切换。点「开始导航」时 `warmup()` 预热以绕过移动端自动播放限制；页面隐藏 / 关闭时停止播报；原生侧回报引擎不可用、媒体音量为 0 等状态时，页面弹一次轻提示。

## 实时导航引擎（要点）

详见 [10_移动端与语音导航.md](10_移动端与语音导航.md)，前端侧关键实现（navigation.js）：

- GPS 点投影到 GCJ-02 局部米制折线（`projectOn`），得到沿线里程与贴线垂直距离；
- 转向指令三级状态机：远距预报（步行 25m / 骑行 50m / 驾车 100m）→ ≤7m 临近动作令 → 剩余 ≤12m 判定到达；相邻 <15m 的连续拐点自动合并；
- **路段方位角吸附**：贴线 ≤30m、在移动（≥0.5m/s）且设备航向与路段方位角夹角 ≤100° 时，箭头直接吸附路段方位角，消除罗盘磁偏 / 噪声；角度最短路径低通平滑，跨正北用"显示角展平"避免 CSS 旋转绕整圈；
- 偏航阈值步行 20m / 骑行 30m / 驾车 35m，精度 >100m 时只提示不强判，连续 2 点确认后静默 POST `/api/route` 重算（冷却 30s），成功后"已为您重新规划路线"；
- 北朝上跟随，用户拖拽地图退出跟随并显示重居中按钮；10 秒无定位回调上抛 GPS 弱网黄条；Screen Wake Lock + 原生常亮桥保持屏幕常亮；到达后弹到达卡并停止播报。

## 路况管理模式 UI

顶栏 🚧 进入，需管理员口令登录（`/api/admin/login`，session 保持，`/api/admin/status` 回显状态）。上报表单支持五种事件类型、名称 / 说明、生效起止时间（不填=立即生效长期有效），点「在地图上选点」进入选点模式，点选后调 `/api/road-conditions/snap` 自动吸附到最近道路。地图上实时渲染路况线型（封闭实线红、缓行虚线等），图例随是否存在封闭 / 缓行事件展开；管理员点事件弹窗可结束（PATCH）或删除（DELETE）。为保证强一致，这些接口在 SW 中走 network-only。

## PWA 与缓存策略

[manifest.json](../static/manifest.json)：standalone 独立运行、竖屏、主题色 `#8B3A3A`、背景 `#FAF8F5`，含普通 / maskable 图标与三条快捷方式（最短 / 风景 / 平坦）。iOS 主屏图标与 apple-mobile-web-app-* 标签在 index.html 头部声明。

[sw.js](../static/sw.js) 的 fetch 事件按 URL 三策略分发（缓存名以文件内 `CACHE_NAME` 为准）：

1. **同源静态资源 cache-first**：CSS/JS/图标命中缓存直接返回；HTML 导航请求 network-first，离线兜底缓存的 index.html；
2. **`/api/*` stale-while-revalidate**：先出缓存再后台静默更新；其中 `/api/road-conditions` 与 `/api/admin` 时效性强，单独 network-only；
3. **第三方与安装包 network-only**：非同源（高德 JS API / amap.com / amapw.com）一律不缓存；`/app/`（APK 与 latest.json）也强制直连——APK 同名 URL 覆盖发版，缓存会让用户永远拿到旧包。

版本纪律：**改动 PRECACHE_URLS 里的任何文件，必须同步把 `CACHE_NAME` 升版**（编号 +1），否则旧 SW 持续返回旧缓存；install 阶段 `skipWaiting`、activate 阶段清掉非当前版本的全部缓存。日常 CSS/JS 内容更新靠 index.html 中 `?v=20260916d` 这类查询串失效。

首页会在 HTTPS 或其他安全上下文中注册 `/sw.js`。注册失败不影响在线使用；已有 worker 升级时先完成新版预缓存，再激活并清除旧缓存。私有会话、运行与管理接口保持 network-only，APK 与版本清单也不进入缓存。

## 安装引导横幅

独立 IIFE 模块（app.js 末尾），UA 含 `WHUWalkerApp/` 时整体关闭（已在原生 App 内）。四个分支：

- Chromium 浏览器：捕获 `beforeinstallprompt`，延迟 2.5s 弹横幅，点安装走原生 PWA 弹窗；
- 微信内：无安装事件，3s 后主动提示「右上角 ⋯ → 在浏览器打开」；
- iOS Safari：展开「分享 → 添加到主屏幕」文字步骤；
- 其他安卓浏览器（QQ / 夸克 / UC / 华为 / 小米等 UA 判定）：按钮直接下载 `/app/whu-walker.apk`。

关闭后 30 天内不再打扰（`whu_walker:install_dismissed_at_v2`），`appinstalled` 后持久关闭。

## 冷启动欢迎覆盖层

首次访问自动弹出（延迟 150ms，避免卡首屏），含五张快捷卡（经典路线、赏樱路线、景点查询、最短路径、推荐景点）与新手提示，点卡片即按 data-action 分发到 `/api/chat`。"以后不再显示"写 localStorage；老用户（已看过 / 会话内已弹）不打扰。整个模块 fail-soft：关键 DOM 缺失时静默退出，不影响主页面。

## 快捷键

`handleGlobalKeydown` 全局绑定，输入框 / textarea 聚焦时除 Esc 外不拦截，Enter 发送、Shift+Enter 换行：

| 按键 | 功能 |
|---|---|
| `1` / `2` / `3` | 切换步行 / 骑行 / 驾车 |
| `F` / `S` / `D` | 风景优先 / 平坦优先 / 最短路径（驾车模式下 S 无效） |
| `R` | 重置对话（按钮闪动反馈） |
| `/` | 聚焦并选中输入框 |
| `?`（或 Shift+/） | 打开快捷键帮助弹窗 |
| `Esc` | 关闭错误 / 帮助弹窗 |

快捷键触发的按钮会加 0.4s `flash` 闪动作为视觉确认；路线生成后，模式栏下方常驻显示三个可访问的偏好按钮并同步 `aria-pressed` 状态。

## 主题与样式

设计系统变量在 style.css `:root`：珞珈秋色——朱红 `--cherry: #8B3A3A`、深绿 `--jade: #2C5F2D`、民国纸张米白 `--paper: #F5F1E8`；路线色另有模式三色（见上）。触摸目标最小 44px（`--touch-min`），字体栈优先苹方 / 微软雅黑，标题用 Noto Serif SC。
