# 珞珈智行文档目录

## 阅读路径（三层）

| 问题 | 唯一入口 | 说明 |
|---|---|---|
| 项目现在是什么状态 | [HANDOFF.md](../HANDOFF.md) | 只有它回答「当前状态」；更新后标注日期 |
| 版本、POI、路网等可核对数字 | [当前事实.md](当前事实.md) | 自动生成；正文不写死数字 |
| 各工作区在哪、干什么 | [项目目录说明.md](项目目录说明.md) | 工作区版图；恢复说明见资料库 `04_代码/工作区索引.txt` |

`development/`、`research/` 与 `superpowers/` 下的文件是**历史过程记录（只读）**，按文件日期理解，不作为当前状态依据；其中「进度/交接/整理」类旧快照已随整理移出，可从 Git 历史恢复。
