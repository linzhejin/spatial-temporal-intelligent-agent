# T5 全量已见草稿：真实 API/worker 开发回放

## 方法和来源

从 `experiments/datasets/scenarios_test_v2_diverse_draft.json` 的 8 个 T5 家族各取 3 条，共 24 条已见编题。`scripts/analysis/probe_visible_t5_replay.py` 在隔离的本机 PostgreSQL 测试库中调用真实 Flask API、LangGraph worker 和任务续接；天气固定，模型调用由本地哨兵和补丁阻断，**没有向模型服务发送请求**。每条路线按实际边 ID 用独立图检查方向、连通、途经顺序与通行属性；候选按完整 POI 集和路网距离重新计算。

审计输入及原始逐轮观察在 `20261025_p1_t5_all_visible_replay.json`，其 SHA-256 为 `d6730bc531a0761f8b13c63e3f9ec27fb48258e64e0dd5fbe4cf039fd28d265f`。报告内 `source_sha256` 固定了草稿、POI、GraphML、路段覆盖和校核决定。单轮模型依赖题被明确标为 `model_required`，不是通过或失败的真实模型结果。

首次宽口径诊断曾得到 0/24。逐字段追查表明判定器把候选阶段暂不展示的原终点、空约束字段与候选阶段不投影的策略误判为错误；本机未配置模型凭证时，单轮任务在 `_make_client` 前就失败。修正判定口径、用仅供进程内部使用的哨兵触发并阻断模型调用后，重新执行全量回放，得到上表分层结果。原始宽口径输出保留在忽略的 `output/experiments/`，不混入最终报告。
