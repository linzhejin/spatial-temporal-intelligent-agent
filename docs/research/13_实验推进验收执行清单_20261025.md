## 共用验收规则

- 所有记录包含 Git 提交、POI/路网/道路层/事件/工具模式/模型配置哈希、运行命令、原始输出哈希、失败与未知原因。开发运行必须标记为开发态。
- T1–T5、O1、D1、V1、V2 分别记录分母、样本来源和结论边界。产品的“核验通过”、合成事件与公开视频模拟位置不能充当独立道路或影像真值。
- 使用同一模型比较三种 Agent 时，固定工具权限、数据、天气/路况输入、事件时钟和请求预算；模型响应身份、实际 HTTP 次数及费用均要留痕。任何一项缺失，该运行只能作开发诊断。
- 已经用于修复代码或调参的题目及同源场景族保留为已见材料，正式留出集必须另行封存。未能独立判定的地点接驳、通行与模糊语义记为未知，不补造通过结论。
- 实验仅写独立测试数据库；公开视频事件必须标记为模拟位置，不能发布到生产路况。
