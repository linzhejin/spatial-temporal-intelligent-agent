# 公开航拍证据适用性审计（2026-10-28）

## 范围与结论

本记录只审计本机已有的五份公开数据报告，未重新运行视觉模型、核查原始标注或评价校园现场。审计脚本为 `experiments/vision_public_evidence_audit.py`；本次输入文件的 SHA-256 和机器可读结果保存在 `experiments/vision_public_evidence_snapshot_20261028.json`。

| 证据层 | 本次查到的材料 | 目前能支持的说法 | 当前阻断 |
|---|---|---|---|
| 人车检测 | VisDrone 验证集报告记录 548 张有对应框标注的图像；Songdo Vision 报告记录完整官方测试集 1084 张图像的检测评测 | 已有**外域检测**数据和既有评测报告；本次没有重跑模型，也没有验证跨航次泛化 | 车辆框不是道路拥堵事件标签；Songdo Vision 测试集按图像随机分割，不能当独立航次实验 |
| 车辆拥堵事件 | Songdo 视频与轨迹关联报告登记 29 段视频 | 视频和轨迹已按场景/会话建立候选关联 | 29 段中精确片段时间重合核实为 **0 段**；没有独立审阅的拥堵起止时间和道路观察区域，因此不能计算拥堵事件准确率或召回率 |
| 可见水体 | 外域人工水体评测报告记录 700 张图像；另有按源视频留出的辅助伪标签报告 | 可分别复核“整幅图可见水体”既有报告及伪标签一致性报告 | 人工水体掩膜没有证明与训练源视频互斥；辅助伪标签不是独立人工真值 |
| 道路积水事件 | 现有水体材料 | 可作为积水模型候选与反例研究的起点 | 缺道路表面淹水掩膜、道路区域与独立审阅的事件标签；不能把湖面、普通湿路或整图水体当作道路积水与通行风险 |
| 事件进入路线 | 本次公开影像报告没有路网边关联或路线响应金标准 | 本次不评价此层 | 应在隔离实验中将模拟道路位置、复核状态、有效期和路线响应单独判分；模拟关联不代表真实定位能力 |

“已有外域报告”只表示报告结构和基本计数在本次审计中一致。原始图像、视频、标注与模型输出尚未由本脚本逐项复算，不能把这份审计写成识别性能验收。

## 复现

在仓库根目录执行下列 PowerShell 命令。脚本读取报告，不上传数据；省略 `--output` 时仅向终端输出 JSON。

```powershell
python -X utf8 experiments/vision_public_evidence_audit.py `
  --visdrone-labels 'D:\LuojiaExperimentData\G1\05_reports\visdrone_detection_label_audit.json' `
  --songdo-detection 'D:\LuojiaExperimentData\G1\05_reports\songdo_vision_v2_detector_eval_20261011.json' `
  --songdo-associations 'D:\LuojiaExperimentData\G1\05_reports\songdo_video_trajectory_associations.json' `
  --visible-water-manual 'D:\LuojiaExperimentData\WHUWalker_vision_research\Floodwater\reports\visible-water-binary-manual-eval-20261012.json' `
  --visible-water-pseudolabel 'D:\LuojiaExperimentData\WHUWalker_vision_research\Floodwater\reports\visible-water-test-video-runtime-pseudolabel-eval-20261012.json' `
  --output experiments/vision_public_evidence_snapshot_20261028.json

python -X utf8 -m pytest -q tests/test_vision_public_evidence_audit.py
```

复现时比较 `source_reports` 中的哈希；文件内容变化后，当前快照不再代表新报告。测试用极小合成报告保护判定边界，不模拟真实识别精度。

## 接下来的非人工工作

1. 对 Songdo 视频和轨迹寻找可复核的精确时间同步依据；同步前只允许轨迹侧弱候选分析，不拿轨迹与画面逐秒比较。即使同步成功，还需独立于模型输出的道路区域和拥堵时间窗标注，才能做事件级评测。
2. 审计已有 FloodNet 数据中道路、淹水类别的定义，以及训练/测试的场景或源视频重合；若存在可独立留出的道路积水真值，再建立道路 ROI 评测。缺乏来源独立性时，继续标记为开发性验证。
3. 在隔离路网中构建受控事件到边、有效期和路线响应的独立判分记录；公开影像只作为模拟观测证据，不发布为当前校园路况。此项与识别结果分表报告。

目前没有必须由学生逐帧标注或逐路勘察才能继续的前置工作。事件精度若没有独立真值，最终只能如实报告为未评测。
