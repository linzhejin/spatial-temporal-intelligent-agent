# 珞珈智行论文实验：按完成条件推进与证据看板

> 本文件是执行入口。日期只说明证据产生时间，不构成等待节点。实验设计与验收口径见 `experiments/protocol_v2.json`；2026-10-16 方案中的 300 题全部人工裁决是历史 v1 要求，不能作为当前门槛。

## 研究边界

主问题是在相同模型、地点、路网、路况、工具权限和预算下，显式任务状态、可追溯空间工具编排和变化更新能否改善校园复合出行任务。论文只能报告已测样本上的效果。图内合法、真实道路可通行、视觉检测准确和用户体验改善是不同结论，不能相互替代。

## 当前实验资产

- `experiments/protocol_v2.json`：新版 T1–T5 协议、三次重复、120 题正式设计；旧 v1 保留作历史。
- `experiments/datasets/scenarios_dev_v2.json`：60 条开发草稿；可用于发现并修复功能缺陷，不能作最终成绩。
- `experiments/datasets/scenarios_test_v2_draft.json`：120 条**编题草稿**；来源于已见的模板与 POI。不得将其重命名为盲测集或据此调参后报告正式效果。
- `experiments/candidate_reference.py` 和 `output/experiments/T2_candidate_reference_draft.json`：不调用产品推荐器，直接用 POI 用途标签和冻结路网算 24 个 T2 候选参考，逐题记录全部可达数、不可达数、前四名及末端接驳风险。9 题需进一步核查。该算法把 POI 吸附到最近节点并按直线估计末端接驳；正式回放必须通过 `--pois` 和 `--graph` 重新计算，不能信任题目预填的距离。接驳不确定时评分为未知，不能当成已实测可达。
- 独立路网覆写审查现在要求 `(u,v,key)` 精确命中冻结图；错误编号不再退回同端点的第一条边。现有 208 条覆写全部精确命中，合成失效编号反例被拒绝。
- `docs/research/10_任务歧义审查卡_待确认.md`：16 张建议答案卡；答复后仍须生成带审查人和证据的独立记录。

## 不等待人工的执行顺序

1. 优先修会改变判分的缺陷，保留回归反例；自动能判的以冻结图、POI 用途和确切事件边为依据。尚不明确的空间通行性记为未知。
2. 用小样本试跑三个同模型条件，记录工具清单、总调用次数、错误、token 与时间；比较前检查权限和输入完全一致。DeepSeek Harness 的实现与版本由官方仓库记录；不能只套其名字调用另一套 Agent。
3. 分开进行 D1 受控事件、V1 视频模拟、V2 标注图像识别。公开视频不存在武大真实路况；视觉输出必须经管理员确认后才影响路由。
4. 同步写论文引言、方法和实验设置。正式测试集不用于修 bug；若暴露问题，该集降级为已见材料并重新封存留出样本。
