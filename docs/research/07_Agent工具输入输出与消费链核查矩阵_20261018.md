# Agent 工具输入、输出与消费链核查矩阵

核查日期：2026-10-18
范围：本地 14 个工具 schema、执行器、LangGraph/Planner 收尾响应、网页消费及现有自动化测试。
边界：这里验证程序合同和模拟模型交互，不代表真实大模型每次都选对工具，也不代表线上或手机端已经验收。

Planner 将工具结果序列化到模型消息；如果结果带有路线或澄清等终止型 artifact，就直接收尾，不再额外调用模型。同时把 `route`、`route_comparison`、`candidates`、`clarify`、`suggestions` artifact 单独保留并拼入最终响应。网页据 `response_kind` 渲染路线、路线比较卡、候选卡或澄清选项；路线与聊天回复的建议芯片由结果展示流程消费。

## 本轮消费链修复

之前的 `task_type=chat` 前端分支只写入回复气泡后就返回，没有消费响应里的 `suggestions`；因此 `suggest_followup` 即使成功返回也会丢在网页之外。第一次加上渲染后，真实浏览器检查又发现建议节点仍在隐藏的路线结果容器里。现将聊天建议节点移动到对应回复气泡之后；没有建议时收起旧路线建议，避免旧按钮残留。JS 回归覆盖建议显示、点击提交、无建议时清理和 DOM 位置；Playwright 本地浏览器以模拟 API 验证建议可见、可点、发出正确查询且无建议下一轮会隐藏旧按钮。该实测未连接生产服务或真实模型。

路线比较消费链也已补齐：`compare_routes` 的可用方案和不可用原因作为结构化 `route_comparison` 响应返回，Planner 用程序生成简明摘要并结束工具循环，不再要求模型复述距离等数值；网页在聊天中展示各方案的距离、估时、相对最短路差值、坡度/景观字段和不可用原因。比较卡是只读内容，不清空或覆盖地图上已有路线。Python 工具/Planner/API、JS 控制流及 PC/手机网页浏览器流程均有对应回归；验证只覆盖本地代码和模拟响应，不代表真实模型调用或生产环境已经验收。

## 结论与后续边界

- 14 个 schema 均有且仅有一个同名执行器；已有测试覆盖主要输入边界、工具结果形状、路线核验与路线比较/候选/澄清 artifact。五选项截断、聊天建议未消费和路线比较缺少专用卡片这三个已定位断点已补齐。
- 路线、路线比较、候选、澄清、建议五类 artifact 有确定的程序消费路径；地点详情、天气、路况的解释仍主要由模型组织。`resolve_poi` 歧义候选还没有独立候选卡。
- 工具注册和本地测试只证明程序合同在固定输入下工作，不证明真实 Agent 工具选择、生成回答忠实度或多轮上下文在所有表达下可靠。2026-10-18 已在隔离本地服务用真实模型回放六个开发种子并采集到实际工具轨迹；这些种子尚未人工裁决，不能报告选工具准确率或端到端成功率。
- 下一步先完成人工工具—意图及空间结果裁决，再用冻结输入补做逐轮“预期工具、实际工具、参数、结果消费和最终回答”对照。真实轨迹已可采集，但缺少独立判据仍不能报告真实 Agent 质量。

## 可选真实模型调用轨迹

为把“真实模型到底选了哪些工具、传了哪些参数、结果如何进入答复”转成可审计证据，工作流提供默认关闭的 `AGENT_TOOL_TRACE_ENABLED=1` 开关。开启后写入既有 run event：开始标记和逐次工具调用元数据。轨迹字段限定为工具名、参数键名、执行状态及 artifact 类型；不记录原始参数值、工具结果正文或模型思维文本。实时实验适配器投影时再次按白名单构造，协议校验器拒绝包含原始参数/响应的记录，并核对逐轮轨迹数量与总调用数。

这项能力已完成代码与本地合同测试，并在六个未裁决开发种子中取得真实轨迹，原始投影位于 `output/experiments/dev_real_agent_baseline_20261018_03.jsonl`。当前可见路线、多途经、天气/路线组合、约束修订和路况查询等实际调用；轨迹只保留工具名、参数键名、执行状态和 artifact 类型，不含原始工具参数及模型思维文本。六题均为开发材料；在人工裁决预期工具、参数和答复之前，不计算工具选择准确率、参数准确率或回答忠实度。正式实验须使用冻结样本，并把原始会话及不必要的用户内容留在评估样本之外。默认不开启不会改变生产运行和事件存储。

## 工具选择的逐轮裁决合同

人工审查协议现为每一轮记录受控 `intent_label` 和可接受工具调用序列 `expected_tools`。后者是工具名称的有序数组列表，允许多个等价序列；“本轮不应调用工具”用 `[[]]` 表示。导入和评分用当前 `agents.tools.TOOL_NAMES` 拒绝未知工具名。

回放记录 `tool_use` 独立诊断：轨迹完整且命中任一人工认可序列为通过，序列不符为失败，追踪关闭或轨迹结构缺失为未知，没有人工预期为未裁决。摘要提供整体及按 `intent_label` 分层的准确率，分母仅计可判定的已裁决轮次；该指标不改写端到端 `task_success`。目前意图标签是人工参考类别，不是模型输出，因此不能称为模型意图分类准确率。

人工审查队列文件：`output/experiments/scenario_adjudication_queue_20261018_intent-tools.xlsx`。截至本次审计，60 个开发场景、72 个用户轮次均仍未完成人工裁决；该工作簿没有预填金标准答案。工具选择准确率仍为空；开发轨迹已经取得，但不得用工具注册测试或系统自己的输出代替独立金标准。
